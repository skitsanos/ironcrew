# IC-025 — Structured output is silently dropped by Anthropic and Responses providers

## Finding

`response_format` (JSON Schema structured output) is documented as a
provider-agnostic capability in `docs/agents.md` ("Forces the LLM to return JSON
conforming to a specific schema"), and the executors pass it on every request
(`src/engine/executor.rs`, `src/lua/dialog.rs`, `src/lua/agent_turn.rs`). Only
the Chat Completions provider maps it: `AnthropicProvider::build_body`
(`src/llm/anthropic.rs`) and `OpenAiResponsesProvider::build_body`
(`src/llm/openai_responses.rs`) never read `request.response_format`, so the
field is silently ignored.

A crew that validates its pipeline on the OpenAI Chat Completions provider and
then switches to Anthropic or the Responses API loses schema enforcement with no
error and no warning, producing free-form text where the flow expects validated
JSON.

## Outcome and validation

**Resolved on 2026-08-19.** All three providers now enforce `response_format`.

`OpenAiResponsesProvider::build_body` (`src/llm/openai_responses.rs`) maps it to
the Responses API `text.format` object for `json_schema` (with `strict: true`),
`json_object`, and `text`.

The Anthropic Messages API has no `response_format`, so
`AnthropicProvider::build_body` (`src/llm/anthropic.rs`) enforces a `json_schema`
with a single-purpose tool carrying the schema. When no other tools are present,
`tool_choice` forces it. When real or server-side tools are available, selection
stays open so they can run first; the provider requires the schema tool before
accepting a terminal response. The response side unwraps that tool input as
message content while leaving genuine tool calls for the executor.

Regression coverage: Anthropic tests assert no-tool forcing, open selection
with real tools, intermediate tool calls, schema unwrapping, and rejection of a
terminal prose response that omits the schema tool. Responses tests
assert `json_schema` and `json_object` mapping and that an absent
`response_format` leaves `text` unset.

Documentation: `docs/agents.md` now carries a per-provider support table
explaining the Anthropic tool-forcing mechanism.

Validation: `cargo test --all-targets` (55 binaries, 0 failures), clippy clean.

Boundary: `json_object` and `text` on Anthropic have no schema to bind and are
not tool-forced; only `json_schema` is enforced there.
