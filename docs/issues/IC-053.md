# IC-053 — Locked TLS dependencies fail the current security advisory gate

## Finding

The required security audit on 2026-10-21 rejected the locked TLS graph. The affected packages were
`rustls 0.23.45`, `rustls-webpki 0.103.15` and `webpki-root-certs 1.0.9`. The findings covered
RUSTSEC-2026-0346 through -0349, RUSTSEC-2026-0382 and RUSTSEC-2026-0383.

## Outcome and validation

Compatible transitive patch updates selected `rustls 0.23.46`, `rustls-webpki 0.103.16` and
`webpki-root-certs 1.0.10`. No advisory suppression or widened direct dependency constraint was added.
The audit and required Rust checks passed on the corrected graph. These security fixes remain in
place; unrelated downstream integration narratives and receipt paths are removed from this page.
