# IC-013 — Dependency audit allowed an unsound transitive warning

## Outcome and validation

**Resolved on 2026-08-07.** The existing RustSec action did not fail on
informational audit warnings, and `Cargo.lock` selected `event-listener 5.4.1`,
which the current advisory database flags under `RUSTSEC-2026-0221` for an
unsound cross-thread tag boundary. The dependency is transitive through
`sqlx-core 0.9.0`.

The lockfile now selects the compatible fixed `event-listener 5.4.2`; its
dependency simplification also removes the no-longer-used `concurrent-queue`
package. CI installs pinned `cargo-audit 0.22.1` and runs
`cargo audit --deny warnings`, so vulnerabilities and informational warnings
fail closed instead of silently passing. Repository-policy coverage requires
both the strict command and fixed lock selection.

The strict audit completed with zero vulnerabilities and zero warnings. Exact
all-target Clippy and the complete default all-target test suite passed after
the transitive update. This resolves the known advisory in the current lockfile;
it does not remove the need to review future advisories or stale audit policy.
