# IC-054 — Repository toolchain pins fail the required latest-stable gate

## Finding

The repository's mandatory latest-stable admission rejected Rust 1.99.0 pins after stable resolved
to 1.99.1. The manifest, toolchain, builder, workflow pins and policy expectations needed to agree.

## Outcome and validation

Managed toolchain references and their policy expectations were updated consistently to Rust 1.99.1.
The required dependency refresh, format, Clippy with denied warnings, default tests, security audit,
repository policy, Lua checks and isolated PostgreSQL/replica checks passed on the qualified graph.
Historical release receipts and paired release-image digests were preserved. These generic fixes
remain in place; downstream product qualification narratives and local filesystem paths are removed.
