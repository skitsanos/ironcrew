# IC-056 — Shared discovery deadline races Python startup in semantic MCP capability acceptance

## Finding

The semantic missing-tools-capability test shares a one-second discovery deadline with deliberate
timeout and caller-abort fixtures. A cold Python startup can exhaust that deadline before capability
validation, producing a timeout instead of the required semantic rejection.

## Required outcome and acceptance

Separate semantic capability acceptance from deliberate timeout fixtures. Cover immediate and delayed
startup with a bounded functional discovery budget, assert the required semantic rejection and exact
discovery requests, and verify that the child process is reaped. Preserve production MCP deadlines
and the existing timeout and cancellation contracts.

The independent test correction is in progress and is excluded from the history-cleanup publication.
Its implementation, regression results and hosted CI completion must be recorded with that change.
This previously issued ID is retained permanently and must not be reused.
