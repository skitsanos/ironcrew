# IronCrew 4.0.2

IronCrew 4.0.2 is a maintenance release. It keeps the v4 functionality and
breaking changes described in the [v4 upgrade guide](v4.0.0.md), including the
PostgreSQL 17 minimum for the lifetime of IronCrew 4.x. It does not change Lua
APIs, CLI or HTTP contracts, storage schemas, or the MCP revision.

## Toolchain and dependencies

- Rust 1.99.0. `rust-version` rises from 1.98.1, so building from source
  requires Rust 1.99.0 or newer. Atomic counters move from `fetch_update` to
  `try_update`, with no behavior change.
- Refreshed dependencies: tokio 1.53.2, mlua 0.12.2, hyper 1.12.0, hyper-util
  0.1.21, jsonschema 0.58.6, rmcp 3.5.1, uuid 1.27.0, thiserror 2.0.21, and
  zeroize 1.9.1. sqlx 0.9.0, tempfile 3.27.0, and portable-pty 0.9.0 are now
  pinned exactly.
- Upstream fixes of note: hyper 1.12.0 corrects HTTP/1 `Content-Length` and
  `Transfer-Encoding` handling and connection-close precedence. jsonschema
  0.58.6 makes `\s` in schema `pattern` keywords match all Unicode space
  separators.
- The builder (`rust:1.99.0-bookworm`), source runtime (`debian:13-slim`), and
  release base (Wolfi) images are re-pinned to current digests.
- MCP stays strictly on `2026-07-28`, the latest published revision when this
  release was cut.

## Repository and evidence integrity

- [IC-050](../issues/IC-050.md): restores the platform-canary assembly
  Dockerfiles to the bytes their receipts recorded. Excludes them from
  Renovate and adds a regression test.
- [IC-051](../issues/IC-051.md): Renovate refreshes the release receipt's
  Wolfi digest in the same change as the runtime Dockerfile. Develop-based
  Renovate runs also apply `develop`'s configuration.
- [IC-019](../issues/IC-019.md) follow-up: the replica admission acceptance
  test waits for process-local cleanup before checking zero active-run
  metrics.

## Upgrade

From 4.0.1, this release is a drop-in replacement. Source builds need Rust
1.99.0. From v3, all
[v4 breaking changes and migration steps](v4.0.0.md#breaking-changes-and-upgrade-checklist)
apply.

## Validation

The release candidate passed these local gates: rustfmt; all-target Clippy with
`-D warnings`; all-target tests (1,550 passed and 3 ignored, across 68 suites);
doctests; `cargo audit --deny warnings` (1,293 advisories, 415 crates); and the
Lua gate (67 declaration and syntax checks, 5 construction evaluations, and 5
offline probes). It also passed the repository policy tests (62), repository
Python tests (76), skills, issue registry (51 findings), module-size policy, and
actionlint 1.7.12. The debug binary reports 4.0.2.

All direct Cargo dependencies were at their latest registry versions. Three
older transitive crates are held back upstream: `crypto-common` 0.1.7
requires `generic-array` =0.14.7; axum 0.8.9 requires `matchit` =0.8.4; and
`sse-stream` stays below 0.3 for rmcp transport compatibility.

The PostgreSQL 17 floor and latest-stable suites, the replica lifecycle and
soak gates, macOS, Windows, and the optimized release build are CI evidence
here. They did not run locally, because the preparation container had no
Docker daemon. Those jobs passed on the `develop` commits that make up this
release, and the release pull request records the exact-head results. This
release claims no new paid-provider or deployed acceptance.
