## Regression and cleanup evidence

The final serial live-PostgreSQL Rust gate on this worktree was:

```text
IRONCREW_TEST_PG_URL="$DATABASE_URL" cargo test --locked --all-features \
  --test postgres_store_test \
  --test multi_replica_http_test \
  --test two_process_replica_acceptance_test -- --test-threads=1
```

It passed 48/48 PostgreSQL-store, 2/2 multi-replica HTTP, and 10/10
separate-process acceptance tests.

Both soak processes exited 0 after graceful shutdown and neither required a
forced kill. The soak and profile runners each removed only their exact
validated prefix and verified zero remaining relations/functions or objects.
After the Rust gate, both test processes were gone and zero other client
sessions remained in the dedicated database. The final fixture cleanup stopped
only captured labeled container ID `8758c17c...`; because it was created with
`--rm`, subsequent `docker inspect` failed. No broad database, Docker, image,
volume, builder, or system prune was used, the pulled `postgres:15` image was
retained, and an unrelated `bi-eval-arango` container was untouched.

The soak continuously drained child output but retained only byte counts,
SHA-256 digests, and secret-canary results. Both streams completed and passed
the secret scan; raw logs were not retained. Profile runtime logs and mock
request/response content were likewise absent from the receipt.
